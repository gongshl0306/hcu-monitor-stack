# GPU 计算节点列表 —— 每行一个采集目标
#
# 格式：<IP>:16080  或  <IP>:<端口>
#   - 跨机部署：写各 GPU 节点的内网 IP（需从中心节点可达）
#   - 中心节点与某 GPU 节点同机：该行写 host.docker.internal:16080
#     （compose 已把 host.docker.internal 映射到宿主机网关）
#
# 以 # 开头的行和空行会被忽略。
# 改完本文件后，在中心节点执行：bash deploy.sh add-node  （重新生成目标并热加载）
#
# 示例（按你的实际节点 IP 修改）：
10.0.0.11:16080
10.0.0.12:16080
