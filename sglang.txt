# SGLang 推理服务接口列表 —— 每行一个
#
# 格式：<IP>:<端口>   （SGLang 服务端口，/metrics 就在这个端口上）
#   - 前提：服务启动参数带 --enable-metrics
#   - 跨机：写服务所在机器的内网 IP
#   - 与中心节点同机：写 127.0.0.1 或 host.docker.internal
#
# 以 # 开头的行和空行会被忽略。
# 改完本文件后，在中心节点执行：bash deploy.sh sglang  （重新生成目标并热加载）
#
# 示例（按你的实际服务地址修改）：
10.0.0.22:8000
10.0.0.22:8001
